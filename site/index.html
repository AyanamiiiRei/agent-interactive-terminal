把终端交给模型，
键盘还在你手里。

普通 exec 工具没有 TTY：程序不进交互模式、长任务看不见、密码漏进对话记录、人和模型没法共用同一个 shell。这里把终端变成有身份、有屏幕、有相位、有租约的资源。

等待是一个查询

terminal_wait 等的是屏幕状态：命中子串、静默、相位、进程退出。命令在跑和程序在问你话是两种事实，返回的 phase 会区分它们，模型该做的动作也就不同。

一屏两投影

人的浏览器拿到序列化 ANSI，模型拿到文本快照。同一块屏幕，两种读法，谁都不用替谁转述。多个等待器互不消费，因为判断依据是屏幕而不是输出偏移。

授权在服务端

只读和封禁是会话的属性，不是浏览器里少发几个按键。封禁之后连尺寸、工作目录和名字都不再被列出，会话列表里只剩一条被隐去的记录。

八个工具

terminal_send 是主力，其余按需出现。上面回放里出现的调用，返回格式就是这里的真实格式。

Tool作用
terminal_open建会话，返回 id、状态行和初始屏幕
terminal_send写入并等待结算；被人握键盘时立即返回排队标记
terminal_wait只等不写，适合看长任务和守日志
terminal_snapshot取屏幕或输出尾部，带 sinceRevision 只回变化的行
terminal_key按一个命名键，例如 ctrl-c 或 page-down
terminal_resize改尺寸，全屏程序立刻收到新大小
terminal_close关会话，连同进程树一起收干净
terminal_list列会话的相位、尺寸、目录和名字；被封禁的会隐去

装起来

在 DeepSeek Harness 里

Plugins → Discover 里添加这个索引，搜索 agent-interactive-terminal，首次安装批准 node-pty 的构建脚本。

https://raw.githubusercontent.com/AyanamiiiRei/agent-interactive-terminal/main/plugin-market.json

从源码

Node 20 以上，外加 node-pty 需要的 C++ 工具链。装好之后 npm run demo 就能看到模型那一侧读到什么。

git clone https://github.com/AyanamiiiRei/agent-interactive-terminal.git
cd agent-interactive-terminal
npm install && npm run build
npm run demo -- "git status"
